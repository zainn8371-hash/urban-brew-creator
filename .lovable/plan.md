# Up Town Cafe website

## What I’ll build
- A premium, warm café homepage with full-screen photography, bold editorial typography, and clear booking/order actions.
- A sticky desktop and mobile navigation with Home, Menu, About, Gallery, Reviews, and Contact destinations.
- Featured menu categories and editable item cards with prices, quantity controls, and an order summary.
- About, café highlights, an editorial gallery, customer reviews, a promotional banner, and contact/location details.
- WhatsApp ordering fallback with a prefilled order message, plus phone, Instagram, and directions actions.
- Responsive layouts and restrained reveal, hover, and image-motion effects.

## Visual direction
- Cream, espresso, muted olive, and warm gold palette.
- High-quality custom café, coffee, and food imagery.
- Elegant editorial headings paired with highly readable body type.
- Premium but approachable styling with restrained corners and shadows.

## Technical details
- Build the main experience at `/` using the existing React app.
- Keep all editable café data—menu, reviews, contact placeholders, and social links—centralized in the page code.
- Use semantic theme tokens in the global stylesheet and add route-specific social metadata.
- Keep order state in the browser and generate a WhatsApp message without requiring an online payment system.
- Verify the finished site on desktop and mobile, including navigation and ordering interactions.

## Assumptions
- Address, phone, WhatsApp, opening hours, and social profile URLs will remain clearly marked placeholders until real details are supplied.
- Menu prices will use Pakistani rupees and can be replaced easily.
